How to Play

  • Join with a room code (or scan the lobby QR code) — no account needed. Playing alone? The host can add a 🤖 computer player from the lobby instead of waiting for a second human.
  • Each question gives everyone 15 seconds. Answer fast and correctly for more points: 200–1000 points based on speed. Wrong or no answer = 0.
  • Every 3rd question is a power round, alternating between:
  • ⚡ Steal Round — the fastest correct answer can steal 150 points from one opponent.
  • 🥶 Freeze Round — the fastest correct answer can freeze one opponent, locking them out of the very next question.
  • After the last question, whoever has the most points wins. Hit Play Again to replay with the same room and code.
